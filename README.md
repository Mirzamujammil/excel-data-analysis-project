# Excel Data Analysis Project

## 📊 Project Overview
This project focuses on cleaning, analyzing, and visualizing data using Excel and Power BI.

## 🔧 Tools Used
- Microsoft Excel  
- Power BI  

## 📌 Key Tasks
- Data cleaning and preprocessing  
- Removing duplicates and handling missing values  
- Data analysis and summary  
- Dashboard creation  

## 📈 Output
An interactive dashboard showing key insights and trends.
